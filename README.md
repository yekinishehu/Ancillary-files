# Ancillary files

**Y. Shehu, "Adaptivity, Anchoring, and the Exact Oracle Complexity of
Stochastic Fixed-Point Iterations."**

This repository contains the code and data accompanying the manuscript.

## Reproducing the numerics (Section 5)

| File | Description |
|------|-------------|
| `generate_figures.py` | Single script reproducing every number, figure and table of Section 5 (Experiments 1-5; Figures 1-5; Table 1). Python >= 3.9 with numpy (scipy only for `scipy.special.gamma` in the rotation-law check; matplotlib optional, for the figure PDFs). Fixed seed `SEED = 20240923`. Run: `python3 generate_figures.py`; add `--greedy` to also run the greedy-adversarial dip search behind Remark "Numerical status of the pointwise statement". |
| `figures/` | Figure PDFs and Table 1 exactly as generated by the script. |

Notes:

* Experiment 5 (Table 1) is **deterministic** (exact arithmetic, no oracle
  noise); the twelve escape times are reproduced to the integer.
* Experiments 1-4 use the Gaussian-noise single-point oracle of Definition
  2.1 with the fixed seed above; reported numbers are averages over
  independent runs, so tiny deviations from the values printed in the paper
  are expected if the seed or numpy version is changed.
* `superseded/` contains `verify_certificate.py`, the computer-assisted
  certificate of the *pre-revision* appendix (see `superseded/NOTE.md`); it
  is not part of the submitted paper.
